# Museum of Us — v4 UI/UX repair

This version fixes the iPhone gallery issues reported in v3:

- removes the horizontal rail that crossed through exhibits
- fixes iOS vertical jump caused by `scrollIntoView()`
- restores complete museum visitors with heads/arms/legs, anchored to the museum wall
- visitors move only with the wall, never with the viewport
- changes typography to a sturdier museum/editorial pairing
- prevents title/label collisions on narrow screens
- improves entrance/foyer art direction and spacing
- preserves sequential exhibit locking and all existing content/assets
