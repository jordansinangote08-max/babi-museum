# NTAG215 NFC setup

Do this only after the GitHub Pages site has a final public URL.

1. Open an NFC-writing app on a phone that supports NFC writing.
2. Create a new **URL / URI** record.
3. Paste the final Museum of Us GitHub Pages URL, for example:
   `https://YOUR-USERNAME.github.io/museum-of-us/`
4. Tap **Write** and hold the NTAG215 card against the phone until the write completes.
5. Test the card on a different NFC-capable phone before giving it to Jirby.
6. Do **not** write the testing `?preview` URL to the card. The real card should use the normal URL so the monthly 25th–26th opening schedule works.

## Optional: lock the tag

Only lock the NTAG215 after the final URL has been tested. NFC tag locking is normally permanent; if the URL ever changes, a locked tag cannot be rewritten.
